# Custom Ship Backgrounds

Add custom background images for your ships here!

## How to Use

1. Find or create an image of your ship
2. Name the file to match your ship name (see naming rules below)
3. Save it as `.jpg` or `.png` in this folder
4. Reload the viewer page to see your custom backgrounds

## Naming Rules

Convert your ship name to a filename by:
- Making it lowercase
- Replacing spaces and special characters with dashes `-`
- Removing extra dashes

### Examples

| Ship Name | Filename |
|-----------|----------|
| `L-21 Wolf` | `l-21-wolf.jpg` |
| `Perseus` | `perseus.jpg` |
| `Aegis Avenger Titan` | `aegis-avenger-titan.jpg` |
| `600i Executive-Edition` | `600i-executive-edition.png` |
| `F8C Lightning` | `f8c-lightning.jpg` |

## Tips

- Use `.jpg` or `.png` format
- Recommended size: 800x600 or larger
- Images will be overlaid with a dark gradient for text readability
- If no custom image is found, the default gradient background is used

## Finding Ship Images

- Star Citizen Ship Matrix: https://robertsspaceindustries.com/ship-matrix
- Community screenshots and artwork
- Official RSI media
- Fan-made renders

---

**Note:** These images are stored locally in your extension folder and are not uploaded anywhere.
